快速开始

就像点外卖：下单（提交任务）→ 等骑手（每隔几秒查一次状态）→ 取餐（下载视频）。下面的例子可以直接复制，把「sk-你的令牌」换成自己的钥匙就能跑。

curl https://ai.939593.xyz/v1/videos 
  -H "Authorization: Bearer sk-你的令牌" 
  -H "Content-Type: application/json" 
  -d '{
    "model": "vela-2.5",
    "prompt": "保持人物身份一致，生成电影感动作视频",
    "images": ["https://example.com/ref-1.jpg"],
    "resolution": "720p",
    "aspect_ratio": "16:9"
  }'

MiniMax H3 全系工作流同样提交到 POST /v1/videos——本站已统一入口，无需使用 /v1/videos/generations 路径。

import requests, time

BASE = "https://ai.939593.xyz/v1"
HEADERS = {"Authorization": "Bearer sk-你的令牌"}

# 1) 创建任务
payload = {
    "model": "minimax-h3-b",
    "prompt": "角色从窗边走向镜头，布料和发丝自然运动",
    "seconds": 5,
    "aspect_ratio": "16:9",
    "input_reference": ["https://example.com/character.jpg"],
}
r = requests.post(f"{BASE}/videos", json=payload, headers=HEADERS, timeout=30)
r.raise_for_status()
task_id = r.json()["id"]

# 2) 轮询状态（5–15 秒间隔）
while True:
    task = requests.get(f"{BASE}/videos/{task_id}", headers=HEADERS, timeout=30).json()
    if task["status"] == "completed":
        break
    if task["status"] == "failed":
        raise RuntimeError(task.get("error", {}).get("message", "task failed"))
    time.sleep(10)

# 3) 下载成品 MP4
mp4 = requests.get(f"{BASE}/videos/{task_id}/content", headers=HEADERS, timeout=120)
open(f"{task_id}.mp4", "wb").write(mp4.content)
print("saved", task_id + ".mp4")

CREATE VIDEO

创建视频任务

提交成功后会马上回给你一个任务编号（id）——这只是「订单已接单」，视频还要再做一会儿。务必把这个编号存下来，查进度、取成品全靠它。

POST/v1/videos
!所有视频模型都用同一个地址提交：POST /v1/videos。网上教程里出现的 /v1/videos/generations 在本站不存在（会报 404），从别家搬代码过来记得先改地址。

公共参数

字段类型说明
modelstring必填。用哪个模型，名字照抄模型目录里的拼写。
promptstring必填。用一句大白话描述你要的画面：谁、在干嘛、什么风格，写得越具体效果越好。
seconds / durationnumber要做几秒的视频。两个名字等效，填一个就行，填整数（如 5、10）。各模型有自己的时长范围（见目录），超了会在扣费前被拦下。
aspect_ratiostring画面形状：16:9 电视横屏、9:16 手机竖屏（发抖音用这个）、1:1 方形。
resolution / sizestring清晰度：480P 省钱、720P 更清楚（部分 Vela 按秒款还有 1080P / 4K）。vela-2.5 固定 720P，填了也忽略。

REFERENCE ASSETS

参考素材全流程（上传 → 生成 → 轮询 → 下载）

手上有段视频、几张图或一段配音，想让 AI 照着它们拍片？四步搞定：先把素材传到本站素材暂存服务拿到直链 → 把直链塞进生成请求对应字段 → 隔几秒问一次进度 → 做好了下载 MP4。下面以参考视频为例走完整流程，图片 / 音频的用法在后面。

POSThttps://h3file.939593.xyz/upload · 第 1 步：上传参考视频
curl -F "file=@my-video.mp4" https://h3file.939593.xyz/upload

返回 {"url":"https://h3file.939593.xyz/f/xxxx.mp4","delete_at":...}——这个 url 就是直链。文件 2 小时后自动删除，请尽快用它提交任务。也可以直接用浏览器打开 h3file.939593.xyz 手动上传拿链接。支持常见视频（mp4 / mov / webm…）、图片（jpg / png / webp…）和音频（mp3 / wav / m4a），单个 ≤200MB。

POST/v1/videos · 第 2 步：带参考视频生成（minimax-h3-720p）
curl https://ai.939593.xyz/v1/videos 
  -H "Authorization: Bearer sk-你的令牌" 
  -H "Content-Type: application/json"

    "resolution": "720p",
    "reference_videos": ["https://h3file.939593.xyz/f/xxxx.mp4"]

保存返回的 id（任务编号）。minimax-h3-720p 固定 720P、5–15 秒、统一 ¥0.15/秒，做几秒付几秒，失败不扣费。

GET/v1/videos/{task_id} · 第 3 步：轮询进度
curl https://ai.939593.xyz/v1/videos/{task_id} 
  -H "Authorization: Bearer sk-你的令牌"

每 5–15 秒查一次，看到 "status": "completed" 就是做好了；failed 是翻车（不扣费）。生成通常需要几分钟，高峰期可能 10–20 分钟，别狂刷。

GET/v1/videos/{task_id}/content · 第 4 步：下载成品

  -H "Authorization: Bearer sk-你的令牌"

    "audio": "https://h3file.939593.xyz/f/yyyy.mp3"
  }'

轮询和下载与上面的第 3、4 步完全相同（换任务编号即可）。

✓素材直链的规矩：必须是公网可访问的链接。没有自己的图床/网盘直链？用上面第 1 步的上传服务就行，2 小时有效期内提交任务足够了。
IMAGE GENERATION

生图 API（OpenAI 兼容）

生图比生视频还简单——发完描述等几秒，图片直接回给你，不用轮询等进度。两种玩法：凭空画（文生图）和改已有的图（图生图，把图片当附件一起发）。需要你的令牌属于「生图」分组。

模型档位计费
gpt-image-21K 档按张计费
gpt-image-2-high4K 档按张计费
gpt-image-2.5-flare2.5 创意档按张计费
POST/v1/images/generations · 文生图
curl https://ai.939593.xyz/v1/images/generations 
  -H "Authorization: Bearer sk-你的令牌" 
  -H "Content-Type: application/json" 
  -d '{
    "model": "gpt-image-2",
    "prompt": "一只戴宇航员头盔的柯基犬，插画风格",
    "n": 1
  }'
POST/v1/images/edits · 图生图
curl https://ai.939593.xyz/v1/images/edits 
  -H "Authorization: Bearer sk-你的令牌" 
  -F "model=gpt-image-2" 
  -F "prompt=把这只柯基改成水彩画风格，保持姿势" 
  -F "image=@corgi.png"

公共参数

字段类型说明
modelstring必填。gpt-image-2 / gpt-image-2-high / gpt-image-2.5-flare。
promptstring必填。文生图描述画面；图生图描述要做的修改。
nnumber生成张数，按张计费。
sizestring可选，如 1024x1024；档位由模型决定。
imagefile仅 /edits：multipart 图片文件，支持 PNG / JPG / WebP。

响应格式

{
  "created": 1789469339,
  "data": [
    {
      "revised_prompt": "一只戴宇航员头盔的柯基犬，插画风格",
      "url": "https://.../xxx.png",
      "b64_json": "iVBORw0KGgo..."
    }
  ]
}
✓结果一次给两种格式：url 是个现成链接，浏览器打开就能看图、右键另存；b64_json 是图片内容本身（给程序用的）。生成失败不扣费；价格以网站「模型广场」为准。
TASK LIFECYCLE

查询任务与下载

像查快递一样：隔几秒查一次（别狂刷），看到「completed」就能取件了。任务有四种状态：

queued已接单，正在排队
in_progress制作中，稍安勿躁
completed做好了，快来取
failed翻车了，看失败原因（不扣费）
GET/v1/videos/{task_id}
curl https://ai.939593.xyz/v1/videos/{task_id} \
  -H "Authorization: Bearer sk-你的令牌"

查询返回 OpenAI 风格的 video 对象：

{
  "id": "cgo...task_id",
  "object": "video",
  "model": "minimax-h3-a",
  "status": "in_progress",   // queued | in_progress | completed | failed
  "progress": 50,
  "created_at": 1757136000,
  "completed_at": 1757136123,
  "error": null              // 失败时为 {"message": "...", "code": "task_failed"}

!查进度时不会直接给视频链接——取成品永远走下面的 /content 下载接口，带上你的令牌就行，这是为了保护你的视频不被别人偷拿。

下载成品

GET/v1/videos/{task_id}/content
curl --continue-at - --retry 5 --retry-all-errors \

下载回来就是普通 MP4，手机电脑都能直接放。还没做好就来取会失败，等状态变成 completed 再来；网断了别慌，接着上次下到的位置继续下就行，千万别重新下单（会重复花钱）。

ERROR HANDLING

错误处理

出问题时别慌，报错信息里都会写原因（message 字段）。找客服或管理员排查时，把「时间 + 模型名 + 任务编号 + 报错内容」一起发过去就好：

// 参数错误（400）
{
  "error": {
    "message": "prompt is required (request id: ...)",
    "type": "new_api_error",
    "code": ""
  }
}

// 任务不存在（400）
{ "code": "task_not_exist", "message": "task_not_exist", "data": null }
状态码含义建议
400填写有误检查模型名拼写、描述是否为空、时长范围、素材链接能否打开。
401 / 403钥匙不对令牌抄错/被禁用，或你的分组用不了这个模型。
402余额不足充值或更换有额度的账号。
404路径或资源不存在确认 API Base URL 与任务 ID；本站无 /v1/videos/generations 路径。
429点太快了歇一会儿再发，别一秒连发好几个。
503没有这个模型多半是模型名拼错了（报 model_not_found），照目录抄一遍。
502 / 504后厨出状况服务器或上游临时抽风，拿任务编号过几分钟查一下，别马上重新下单。
上线检查正式接入前：用真实域名和 HTTPS 跑通创建 → 轮询 → 下载全链路；确认令牌不出现在日志与前端；为失败、余额不足、429、超时与重复提交写好明确处理分支。
