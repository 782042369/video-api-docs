QUICKSTART

快速开始

视频生成是异步流程：提交任务 → 轮询状态 → 下载成品。把示例中的域名和令牌替换为自己的配置。

curl https://ai.939593.xyz/v1/videos 
  -H "Authorization: Bearer sk-你的令牌" 
  -H "Content-Type: application/json" 
  -d '{
    "model": "sd-2.5",
    "prompt": "保持人物身份一致，生成电影感动作视频",
    "images": ["https://example.com/ref-1.jpg"],
    "resolution": "720p",
    "aspect_ratio": "16:9"
  }'

SD-2.5 固定输出 30 秒 / 720P，按次计费，请求中的 seconds、duration、size 会被忽略。

curl https://ai.939593.xyz/v1/videos 
  -H "Authorization: Bearer sk-你的令牌" 
  -H "Content-Type: application/json" 
  -d '{
    "model": "minimax_h3_t2v",
    "prompt": "海边日落，镜头缓慢向前推进，电影质感",
    "seconds": 8,
    "aspect_ratio": "16:9",
    "resolution": "720P"
  }'

MiniMax H3 全系工作流同样提交到 POST /v1/videos——本站已统一入口，无需使用 /v1/videos/generations 路径。

import requests, time

BASE = "https://ai.939593.xyz/v1"
HEADERS = {"Authorization": "Bearer sk-你的令牌"}

# 1) 创建任务
payload = {
    "model": "minimax_h3_i2v",
    "prompt": "角色从窗边走向镜头，布料和发丝自然运动",
    "seconds": 5,
    "aspect_ratio": "16:9",
    "input_reference": ["https://example.com/character.jpg"],
}
r = requests.post(f"{BASE}/videos", json=payload, headers=HEADERS, timeout=30)
r.raise_for_status()
task_id = r.json()["id"]

# 2) 轮询状态（5–15 秒间隔）
while True:
    task = requests.get(f"{BASE}/videos/{task_id}", headers=HEADERS, timeout=30).json()
    if task["status"] == "completed":
        break
    if task["status"] == "failed":
        raise RuntimeError(task.get("error", {}).get("message", "task failed"))
    time.sleep(10)

# 3) 下载成品 MP4
mp4 = requests.get(f"{BASE}/videos/{task_id}/content", headers=HEADERS, timeout=120)
open(f"{task_id}.mp4", "wb").write(mp4.content)
print("saved", task_id + ".mp4")

CREATE VIDEO

创建视频任务

参数校验通过后返回任务对象（含 id 与初始状态）；这只代表任务已受理并进入提交队列，不代表视频已经完成。请立即保存返回的 id。

POST/v1/videos
!SD-2.5 与 MiniMax H3 全系模型统一提交到 POST /v1/videos。本站不提供 /v1/videos/generations 路径（返回 404），从其他平台迁移的代码请先改写入口地址。

公共参数

字段类型说明
modelstring必填。模型 ID，见上方模型目录。
promptstring必填。描述画面、动作与镜头。
seconds / durationnumber视频时长（秒），二选一，duration 为兼容别名。H3 工作流上限见模型目录；超限会在扣费前返回 400。
aspect_ratiostring画幅比例：16:9 横屏、9:16 竖屏、1:1 方形。
resolution / sizestring分辨率档位（如 480P、720P、1080P）。SD-2.5 忽略此参数。

各工作流参考素材

模型素材字段说明
sd-2.5images: string[]参考图 URL 数组，最多 10 张；推荐使用 images（也兼容 image_urls）。
H3 全系input_reference: string[]参考图 URL 数组，最多 9 张，重复 URL 自动去重；兼容 image / images / image_url / image_urls / reference_images，也可用 ref_image_0…ref_image_8 逐张指定。
minimax_h3_first_lastfirst_frame / last_frame: string首帧与尾帧图片 URL。
minimax_h3_lipsync*audio: string音频文件 URL，用于口型对齐。

✓素材 URL 必须是公网可访问的 HTTP(S) 直链，不能只在本机或局域网可见，也不能写成 Markdown 链接形式。素材无法访问的任务不会按成功视频扣费。
TASK LIFECYCLE

查询任务与下载

建议按 5–15 秒间隔指数退避轮询，不要高频请求，也不要对同一素材重复创建任务。任务对象状态机如下：

queued已受理，正在提交到生成队列
in_progress排队或生成中，继续轮询
completed成功，可下载成品
failed失败，查看 error.message
GET/v1/videos/{task_id}
curl https://ai.939593.xyz/v1/videos/{task_id} \
  -H "Authorization: Bearer sk-你的令牌"

查询返回 OpenAI 风格的 video 对象：

{
  "id": "cgo...task_id",
  "object": "video",
  "model": "minimax_h3_t2v",
  "status": "in_progress",   // queued | in_progress | completed | failed
  "progress": 50,
  "created_at": 1757136000,
  "completed_at": 1757136123,
  "error": null              // 失败时为 {"message": "...", "code": "task_failed"}
}
!查询响应不包含成品视频直链。下载成品一律使用下方 /content 接口，凭你的令牌获取；不要尝试从响应中提取第三方 URL。

下载成品

GET/v1/videos/{task_id}/content
curl --continue-at - --retry 5 --retry-all-errors \
  -H "Authorization: Bearer sk-你的令牌" \
  -o "{task_id}.mp4" \
  https://ai.939593.xyz/v1/videos/{task_id}/content

返回 video/mp4，支持 GET / HEAD 与断点续传。任务尚未完成时调用会失败，请等状态变为 completed 再请求；网络中断后保留已下载的临时文件，从中断字节继续，不要重新创建任务。

ERROR HANDLING

错误处理

记录 HTTP 状态码、error.message 与任务 ID，便于排查。本站错误响应统一为 JSON 格式：

// 参数错误（400）
{
  "error": {
    "message": "prompt is required (request id: ...)",
    "type": "new_api_error",
    "code": ""
  }
}

// 任务不存在（400）
{ "code": "task_not_exist", "message": "task_not_exist", "data": null }
状态码含义建议
400参数错误 / 任务不存在检查模型、提示词、时长、分辨率与素材 URL。
401 / 403认证或权限失败检查 Bearer 前缀、令牌状态与可用分组。
402余额不足充值或更换有额度的账号。
404路径或资源不存在确认 API Base URL 与任务 ID；本站无 /v1/videos/generations 路径。
429速率 / 并发超限降低提交速度并退避重试。
503模型无可用渠道确认模型 ID 拼写（本站未提供的模型会返回 model_not_found）。
502 / 504网关或上游异常保留任务 ID 稍后查询，不要立即重复创建。
上线检查正式接入前：用真实域名和 HTTPS 跑通创建 → 轮询 → 下载全链路；确认令牌不出现在日志与前端；为失败、余额不足、429、超时与重复提交写好明确处理分支。
